# Python Calculator

A simple command-line calculator built in Python that performs basic arithmetic operations.

## Purpose
This is my first Python project as a B.Tech CSE student. It helped me practise taking user input, using variables, and performing calculations in code.

## Tools Used
- Python 3
- GitHub for storing and sharing the code

## Implementation
The program asks the user to enter two numbers. It then calculates and prints their sum, difference, product, and quotient using the operators +, -, *, and /.

## How to Run
1. Install Python 3 on your computer.
2. Download or copy the file `calculator.py`.
3. Open a terminal in the file's folder and run: `python calculator.py`
4. Enter two numbers when asked.

## Outcome
The program works correctly and shows the four results for any two numbers. It taught me how input and output work in Python.
